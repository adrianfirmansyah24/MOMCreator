# Aset visual MoM Creator

- File final: [`assets/microphone-studio.png`](assets/microphone-studio.png).
- Metode: built-in imagegen, satu aset baru dengan `transparent_background: true`. Bukan fallback CLI.
- Fungsi: objek pusat pada halaman Rapat, mengikuti komposisi video referensi pengguna dan disesuaikan ke konteks rekaman rapat.
- Output asli disalin ke workspace; transparansi dipertahankan. Animasi dan parallax dikerjakan dengan CSS/JavaScript. PNG tidak mengandung salinan UI produk.
